# Trike Tumble

Colorful 3D cartoon downhill party racing on three-wheeled drift trikes.
Godot 4.7.2 · GDScript · Mobile renderer.

**Run:** open the folder in Godot 4.7.2 and press Play (F5), or
`<godot-binary> --path .`

**Controls:** W/↑ accelerate · S/↓ brake/reverse · A/D/←/→ steer ·
SPACE + steer drift (release for boost) · R reset · ESC pause ·
after a wipeout: WASD/arrows run, E get back on the trike
